# palaeo-starwars

This respository contains an in-progress paper that will document the origin of the bones used for the Krayt Dragon in the original _Star Wars_ as (we think) casts of the Carnegie _Diplodocus_.

Feel free to read [the in-progress manuscript](TaylorEtAl-Carnegie-Diplodocus-in-Star-Wars.md).

Anyone is welcome to [file issues](https://github.com/MikeTaylor/palaeo-starwars/issues).
